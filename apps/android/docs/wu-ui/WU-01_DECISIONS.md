## A. 当前已确认（来源：近期 UI 讨论／组内反馈）

| 项目 | 当前结论 | 范围／说明 |
| --- | --- | --- |
| 产品视觉基调 | 首页强调简洁、艺术风景和季节感 | UI 方向 |
| 背景方向 | 小组讨论采用 **A＋B 结合探索** | 组合机制未定 |
| 方案 A 的植物变化 | 植物只随自然日期、季节或节气变化 | 不与健康成绩／签到绑定 |

| 手机系统栏 | UI 图中不自行绘制 Wi-Fi／电量等为 App 元素 | 实现应处理系统安全区 |
| 动态油画 | 本阶段暂缓，先做静态背景 | 非永久否决 |

## B. 候选／待决定

| 事项 | 候选想法或未决点 |
| --- | --- |
| A＋B 结合方式 | 背景双模式切换 vs 固定树＋可变环境 |
| 苹果树素材精度 | 四季扩充到约 12 阶段及可选节气差异；尚未正式定稿 |
| 方案 B 素材机制 | 每日更换、主题随机、按偏好选风格、可手动换图等 |
| 艺术风格 | 油画为主要参考；水彩／柔和数字插画等候选 |
| 健康摘要 | 具体指标、位置、更新时间、数据缺失策略 |
| 底部栏目 | 先前“首页／健康／计划／陪伴”设想与仓库现有“今日／四时／探索／我的”有差异 |
| 宠物形象 | 布偶猫是近期示意形象，最终角色未定 |

| 正式素材 | 一致性、授权／版权、分辨率、适配与资源体积 |
| Figma 交付 | 概念图已有，可编辑规范稿与安卓真机验证尚待完成 |

## C. 与仓库现状的冲突／接口边界

1. 仓库 README 和 apps/android/README.md 仍以“今日／四时／探索／我的”为 Android 起点；UI 讨论中的四栏导航不是自动获批的路由变更。
2. 仓库中原有 Stack-chan 实体陪伴探索不因“首页改成独立宠物板块”而自动废止。
3. GitHub 当前记录 Android 仍为静态起点；设计示例中的健康数据为 Demo，不能当作真实穿戴设备已接通。
4. 医疗安全规则由团队统一制定，UI 不自行解释异常或降低安全边界。
5. 本组文档仅写入个人分支的 apps/android/docs/wu-ui/，不修改 main 或其他成员路径。
