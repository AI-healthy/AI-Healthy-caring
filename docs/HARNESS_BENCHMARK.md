# V0.9 Harness Benchmark · synthetic-v1

仅离线合成测试。实验不读取真实数据库、网络、模型或机器人，不根据结果筛选种子，不是临床或用户研究。
预先固定随机种子42、43、44，报告每个种子，每种子6组×12例共72个场景；4种方法成对复用相同的历史与测试偏好，单种子288轮排序，3种子共864轮。
每种方法独立身份与业务记录，使用临时 SQLite；合成 fixture 直接写入已完成会话和合法反馈，
真实 Harness create_run、候选过滤、记忆检索、RuleRanker 和计划安全门负责实际决策。
通过固定时间和排序稳定键复现实验。测试偏好从独立于决策输出的生成器产生；不是观测到的真实体验。

## 记忆对照
- no_memory：同样的规则、当前状态和显式偏好，关闭记忆；
- static_memory：与衰减版相同的候选过滤、窗口、每活动上限、反馈总预算，以等权平均聚合（含相同平滑）；
- decay_memory：生产记忆检索与时间衰减；
- decay_and_behavior：生产衰减记忆 + 近期重复惩罚。

场景：稳定偏好、偏好迁移、稀疏历史、评分噪声、近期重复、时间预算限制。
生成器包含当前效用与历史评价之间的预设关系，部分场景有意构造偏好变化和重复后的效用下降；
这些假设可能有利于相应机制，不能用于声称真实用户增益。显式偏好、精力与效用也可能不一致。
每例仅一轮查询，不是在线学习回合；没有估计真实接受率、坚持率或身心健康改善。
指标：Top-1 最大效用命中（允许并列）、Top-3 命中、平均首选模拟效用（1–5）、
平均 regret（候选最大效用减首选效用）、反馈/行为召回条数。报告总表和每个场景组；paired 返回按案例首选模拟效用比较的胜/平/负以及平均差值。
不预设哪种算法必须赢，CI 只验证数据隔离、可复现性、候选约束与门控契约，不检查排名增益。
区分静态和衰减版的唯一变化为评分聚合权重；额外行为版改变重复惩罚。
样本为合成非独立用户，未做统计显著性检验。

## 主动陪伴检查
13个固定标注场景，涵盖可用、关闭、无可用声明、勿扰、活动中、待确认、时间不足、暂停、过期、
冷却、频控、勿扰结束边界、冷却结束后。使用实际调度器的单用户原子调度与实际投递校验。
独立的 expected 标签是手写契约，ungated_counterfactual 只是“每次都发邀请”的离线反事实，
不会真的发消息或执行操作。测量 TP/FP/TN/FN、precision/recall；
此组验证约束一致性而不是实际时机识别精度或低打扰用户体验。

## 复现
```bash
cd services/api
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,mcp]'
python -m shiyi_api.benchmark --seed 42 --per-cohort 12 --assert-gates --output /tmp/shiyi-eval
```
输出 summary.json（含逐例数据）、ranking_rows.csv、gate_rows.csv。
CI 对42、43、44运行同样命令并分别保存 artifact（seed-42、seed-43、seed-44），全部结果都应报告。可更换种子/规模做稳健性分析，不应只挑提升最大的种子。
后续预注册真实用户研究、固定基线、记录接受/拒绝及完成率、主观打扰评分、成本与延时；
须自愿参与、隐私审查和明确授权，勿将合成结果替代真实评估。
