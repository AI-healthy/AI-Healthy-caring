## 4. 最新 UI 候选与资源制作要求

- 首页采用“固定苹果树＋变化艺术背景”作为近期**个人初步倾向**，组内仍需确定融合机制与更新频率。
- 设计时应分开**苹果树前景、风景背景、UI 图层**，先验证透视、光照和艺术笔触的一致性。
- 首页顶部保留 App 名称、日期／节气、个人入口；底部为简洁图标导航。
- 可选三环活动组件：默认无数字、指标可从**可获得且具备合理每日目标**的活动项中自定义，点击直接进入健康页面；不可把心率等生理测量值生硬当作目标完成率。
- 首页不放 Stack-chan（独立陪伴页面）、“今日时宜”大卡和重复计划卡。
- 静态画作优先；动态油画暂缓。
