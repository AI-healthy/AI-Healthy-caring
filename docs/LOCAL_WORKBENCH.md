# V1.0 第一阶段 · 本地集成与开发工作台

从仓库根目录执行：
```bash
git fetch origin
git switch feat/xu-session-api
git pull --ff-only
bash scripts/run_local.sh
# 可选： bash scripts/run_local.sh --port 8080
```
Python 3.11+；首次安装依赖需联网。访问 http://127.0.0.1:8000/workbench（或指定端口）。
脚本启动本地 Uvicorn 和独立 scheduler，共享临时 SQLite；忽略既有 SHIYI_DB_PATH、开发身份和模型配置，
强制使用规则和空的预配置身份。Ctrl+C / SIGTERM 停止进程并清理临时目录；强制 kill -9 时无法保证清理。
不接受公网监听或真实记录。没有持久化生产部署、Docker、真实手机/机器人网络接入。

## 操作
1. 创建临时测试账号（随机用户名与密码）并绑定模拟器。凭证只存页面内存，不打印。
2. 勾选体验/行为记忆，设置偏好并保存；输入模拟精力和分钟，生成方案、查看真实 API trace。
3. 选择活动，开始；可发送 happy 表情模拟命令，模拟独立设备 ACK 与完成回执。
4. 手动确认活动完成与体验评分，查询记忆；可重置记忆使用窗口并重新规划。
5. 显式声明可用30分钟并选择模拟通道；worker 扫描后查询邀请，模拟端收执；用户仍要在工作台选择方案。
   不在勿扰/冷却/有任务时创建新邀请。首次扫描可能需要等到 worker 下一个扫描周期。
6. 暂停调度或退出（撤销本地模拟设备、停止声明、退出登录）。刷新页面会丢失内存凭证；
   重新创建测试账号，停止启动器后临时数据库清除。

工作台使用既有 REST API，无数据库旁路；不自动创建活动、提交反馈或发送真实设备命令。
所有返回及阶段 trace 仅是程序实际响应，不是模型思维链。模拟收执不代表真实显示/动作。
页面默认为关闭，仅 SHIYI_DEBUG_WORKBENCH=1 且请求来源与主机为 loopback 才提供；
不能把这一检查当作生产级安全控制。不要在公开监听、反代、共享机器或真实数据数据库上启用。
没有浏览器自动通知、真实 LLM、真实穿戴、Android 集成或硬件控制。
真实前端由 wu 开发，真机协议由 lan 联调，RAG/策略由 fu 维护。
